# LeetCode Problem Collection

A comprehensive collection of 150 curated LeetCode problems organized by topic, with multiple solution approaches and detailed explanations optimized for spaced repetition learning.

## Overview

This collection contains **150 problems** spanning 18 different categories, from fundamental data structures to advanced algorithms. Each problem includes:

- Multiple solution approaches (from brute force to optimal)
- Detailed time and space complexity analysis
- Step-by-step walkthroughs with examples
- Common mistakes and pitfalls
- Real-world domain applications
- TTS-friendly semantic descriptions for each line of code
- Implementations in Python, JavaScript, and Go
